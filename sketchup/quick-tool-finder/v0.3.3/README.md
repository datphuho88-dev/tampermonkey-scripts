# Tìm Công Cụ Nhanh v0.3.3

Bản sửa lỗi lưu công cụ đã ghim sau khi khởi động lại SketchUp/Windows.

## Thay đổi

- Giữ nguyên toàn bộ tính năng của v0.3.2.
- Danh sách ghim được lưu đồng thời trong SketchUp Preferences và file dự phòng tại AppData.
- Khi SketchUp khởi động, Quick Tools được tự khôi phục nhiều lần sau 0,8s / 2,5s / 5s để tương thích các plugin load chậm.
- Tự di chuyển dữ liệu ghim cũ sang cơ chế lưu bền hơn khi có thể đọc được dữ liệu v0.3.2.

File cài đặt: `tim_cong_cu_nhanh_v0.3.3.rbz`.
