# Quick Tool Finder v0.3.1

Bản tối ưu giao diện và độ mượt, giữ nguyên các chức năng của v0.3.0.

## Điểm mới
- Giao diện gọn, sáng/tối tự động theo hệ thống.
- Mã phiên bản hiển thị ngay ở đầu cửa sổ.
- Tìm kiếm debounce nhẹ để giảm render thừa khi gõ nhanh.
- Di chuyển bằng phím ↑/↓ chỉ đổi trạng thái dòng đang chọn, không render lại toàn bộ danh sách.
- Bộ lọc nhanh: Tất cả / Đã ghim / Tên gợi nhớ.
- Nút refresh có trạng thái xoay trong lúc quét lại.
- Giữ nguyên: chạy công cụ, tên gợi nhớ, phím tắt, ghim ra Quick Tools, icon gốc nếu có.

## Cài đặt
SketchUp > Extension Manager > Install Extension > chọn `quick_tool_finder_v0.3.1.rbz`.
