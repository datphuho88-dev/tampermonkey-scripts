# Quick Tool Finder v0.3.0

## Mới trong bản này

- Nút **📌 Ghim** ở từng kết quả tìm kiếm.
- Công cụ được ghim xuất hiện ngay trên toolbar riêng **Quick Tools** của SketchUp.
- Danh sách ghim được lưu qua các lần mở SketchUp.
- Ưu tiên dùng icon gốc của công cụ; nếu không lấy được icon thì dùng icon ghim mặc định.
- Tên gợi nhớ tiếp tục được dùng làm tooltip/tên command cho công cụ ghim.
- Cải thiện khả năng tìm lại command đã lưu nếu plugin gốc nạp chậm hơn Quick Tool Finder.

## Cách dùng

1. Mở Quick Tool Finder.
2. Tìm công cụ, ví dụ `Make Box`.
3. Có thể đặt tên gợi nhớ `Hình vuông` bằng **✎ Tên**.
4. Bấm **📌 Ghim**.
5. Công cụ sẽ xuất hiện trên toolbar **Quick Tools** và bấm trực tiếp để chạy.

Nếu toolbar bị ẩn: vào `Extensions > Quick Tool Finder > Hiện thanh Quick Tools đã ghim`.
