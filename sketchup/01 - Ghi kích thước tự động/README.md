# VADA Auto Dim

Plugin SketchUp tự động ghi kích thước cho các đối tượng khó bắt điểm, đặc biệt là mặt bàn tròn/mặt cong.

**Bản hiện tại:** `v1.1.0`

## Mục tiêu

- Hỗ trợ dim nhanh các mặt bàn tròn.
- Giảm thao tác bắt điểm thủ công.
- Thông tin hiển thị trực quan, ít rối.
- Giao diện tiếng Việt, nền đen `#000000`, hiển thị version.
- Toolbar/icon phải rõ chức năng khi hiển thị nhỏ trong SketchUp.

## Trạng thái mã nguồn

Cấu trúc GitHub đã được tạo. Source/RBZ chính xác của `v1.1.0` cần lấy lại từ artifact cũ để tránh đưa bản tái dựng khác với phiên bản đã kiểm thử.
