# Tampermonkey Scripts

## Danh sách code

- 🧰 **VADA - Auto Workflow - Chọn ngày • Tìm kiếm • Tải file • 12 tháng**  
  Ghi nhớ các ô/nút trên website, chọn nhanh khoảng ngày, chạy tìm kiếm và tải file tự động, hỗ trợ chạy lần lượt 12 tháng.

- 🏦 **ACB - Xuất Excel - Tự tải đủ 12 tháng**  
  Tự chọn năm/tháng trên ACB ONE BIZ và xuất Excel lần lượt từ tháng 01 đến tháng 12.

- 🧾 **Thuế DVC - 01-GTGT - Chọn năm • quý • khoảng ngày**  
  Hỗ trợ tra cứu tờ khai 01/GTGT, chọn nhanh năm/quý và điền khoảng Từ ngày / Đến ngày.

> Quy ước tên: icon + website/chức năng chính + các tính năng nổi bật để dễ tìm và quản lý.
